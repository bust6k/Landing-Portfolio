PWC — асинхронный веб-фреймворк на Python. В 6 раз быстрее Django, без ORM-магии и без обязательной структуры проекта. Хендлеры роутеров — в любом порядке, в одном файле. Один импорт, один декоратор, один запуск.

SPEED

В 6 раз быстрее Django

42 000 req/s на одном ядре. ASGI из коробки, zero-copy роутинг, собственный JSON-сериализатор.

ROUTER

Хендлеры в любом порядке

Не нужно группировать роуты. PWC сам собирает дерево по путям и весам — даже если /user/{id} объявлен раньше /.

ZERO-CONF

Никаких settings.py

Один файл — целое приложение. Никаких manage.py, миграций, apps, INSTALLED_APPS и «где тут моя модель».

BATTERIES

Всё включено

DI, валидация, сессии, WebSocket, ORM-lite, тесты. Модули подключаются по одному импорту, а не по 40 строкам конфига.

ANY ORDER

Дерево роутов строится после загрузки модуля, а не по порядку строк

Объявляйте /user/{id} до /, переопределяйте префиксы через @app.group, монтируйте под-приложения где угодно. Django бы упал с 404 — PWC просто работает.
